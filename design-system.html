Design system

Clay, glass & soft light.

Kargonaut uses three surface languages on purpose. Clay is for objects you press, glass is for panels that float over context, and neumorphism is for controls you adjust. Each one has a job, so they never fight.

The three styles side by side

01

Claymorphism

Puffy, tactile and friendly. Used for cards, stat tiles and primary calls to action.

Express Road Card lifts and tilts on hover. 
.clay {
  background: linear-gradient(145deg,
    var(--clay-from), var(--clay-to));
  border-radius: 30px;
  box-shadow:
    14px 16px 32px rgba(0,0,0,.5),
    inset -8px -10px 18px rgba(0,0,0,.35),
    inset 8px 8px 16px rgba(255,255,255,.09);
}
02

Glassmorphism

Frosted, translucent panels that keep the colourful context visible. Used for navigation, overlays and data panels.

03

Neumorphism

Soft, extruded or pressed into the surface. Used only for controls: inputs, switches, segments and dials.

Use clay when…

the element is a thing: a service, a plan, a stat, a primary button.

Use glass when…

a surface sits on top of rich context: the nav bar, panels, toasts, tooltips.

Use neumorphism when…

the element is adjustable: inputs, switches, steppers, segments and dials.
